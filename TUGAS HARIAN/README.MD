
# Analisis Prediksi Jumlah Pembelian Konsumen E-Commerce

## 1. Deskripsi Proyek
Proyek ini merupakan penelitian bidang Teknologi Informasi yang bertujuan memprediksi jumlah pembelian konsumen e-commerce menggunakan metode Regresi Linear Berganda.

## 2. Tujuan Penelitian
- Menganalisis karakteristik dan perilaku konsumen.
- Membangun model prediksi jumlah pembelian.
- Mengevaluasi performa model regresi.

## 3. Dataset
Nama file: Ecommerce_Consumer_Behavior_Analysis_Data.csv

Format: CSV

Jumlah data awal: 1.000 baris

Jumlah atribut: 28 kolom

Dataset memuat informasi mengenai usia, frekuensi pembelian, loyalitas merek, rating produk, kepuasan pelanggan, dan jumlah pembelian.

Sumber dataset: Cantumkan tautan Kaggle asli apabila sumbernya telah diverifikasi.

## 4. Metode
Metode yang digunakan adalah Regresi Linear Berganda.

Variabel target (Y):
- Purchase_Amount

Variabel prediktor (X):
- Age
- Frequency_of_Purchase
- Brand_Loyalty
- Product_Rating
- Time_Spent_on_Product_Research(hours)
- Return_Rate
- Customer_Satisfaction
- Time_to_Decision

## 5. Teknologi yang Digunakan
- Python
- Jupyter Notebook
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

## 8. Evaluasi
Performa model dievaluasi menggunakan:
- MAE (Mean Absolute Error)
- RMSE (Root Mean Squared Error)
- R² (Coefficient of Determination)

Nilai evaluasi dan kesimpulan akhir diisi berdasarkan hasil eksperimen yang benar-benar diperoleh.
